# ADR-012 — Release re-applies the bot's commits onto the current default branch

- **Status:** Accepted (2026-11-21). **Amends [ADR-004](ADR-004.md)** (restart/branch behaviour).
- **Decision area:** D4 State (also D5 Tools / GitHub permissions)

## Context (what a real run showed)

Run [44902438357](https://github.com/Ohshit-ak/tinydb/actions/runs/44902438357) (issue #3) passed
stages 1–4, then the `release` job failed: `git push … autose/issue-3` was rejected.

While the agents were working, `main` had moved: a maintainer had pushed a change to
`.github/workflows/autose.yml`. The bot's branch was built on the *old* `main`, so it carried an
older copy of that workflow file. GitHub refuses any `GITHUB_TOKEN` push that would change a workflow
file, and a token cannot be granted the `workflows` permission.

ADR-004 assumed the base commit is still the head of the default branch at release time. That is
false for long runs. Runs take 30+ minutes on free-tier models, so this is not an edge case.

## Decision

- `release` fetches the bundle and re-applies the bot's commits onto the current head of the default
  branch (`git rebase --onto <default head> <base> <branch>`). It then re-checks the path allowlist
  against the new base and pushes.
- A rebase conflict stops the run at stage 5, with the reason recorded (no silent merge).
- The CI job (stage 5 check) runs on the *rebased* head, so the tests that gate the review cover the
  code that is actually proposed.

## Alternatives considered

- **Push with a PAT or GitHub App token that has `workflows` permission.** It would work, but a
  long-lived credential with workflow-edit rights is exactly what ADR-005 avoids.
- **Freeze `main` during runs.** This blocks maintainers, and it cannot be enforced.

## Consequences

- Stage-4 tests ran on the old base, while CI runs on the new one. CI catches any interaction
  between the two.
- The run was recovered by re-running only the failed `release` job: the artifacts and the bundle
  from stage 4 were reused (ADR-004's per-run artifacts made that possible).
